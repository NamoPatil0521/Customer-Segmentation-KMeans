 Customer Segmentation using K-Means Clustering

Project Overview
This project focuses on customer segmentation using the K-Means clustering
algorithm. The objective is to group customers based on their demographic
and purchasing-related characteristics.

Customer segmentation helps businesses understand different types of
customers and develop targeted marketing strategies.

Objective
To segment customers into different groups based on their similarities
using K-Means clustering.

Dataset
The project uses the Kaggle Customer Segmentation Dataset.

The dataset contains customer information such as:

- Gender
- Age
- Ever Married
- Profession
- Work Experience
- Spending Score
- Family Size
- Graduation Status

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Jupyter Notebook

Machine Learning Algorithm

K-Means Clustering

K-Means is an unsupervised machine learning algorithm that divides data
into groups called clusters based on similarities between observations.

Project Workflow
1. Import required libraries
2. Load the dataset
3. Explore the dataset
4. Check data types
5. Handle missing values
6. Check duplicate records
7. Encode categorical variables
8. Scale the features
9. Apply the Elbow Method
10. Calculate Silhouette Score
11. Select the number of clusters
12. Apply K-Means clustering
13. Analyze customer segments
14. Visualize the clusters
15. Save the final results

Results
The K-Means algorithm successfully grouped customers into different
segments based on their characteristics.

The clusters were analyzed using features such as:

- Age
- Work Experience
- Family Size
- Spending Score
- Profession
- Marital Status
- Graduation Status

These customer segments can help businesses develop personalized
marketing campaigns and improve customer engagement.

Project Files

- `Customer_Segmentation_KMeans.ipynb` - Complete Jupyter Notebook
- `Train.csv` - Training dataset
- `Test.csv` - Testing dataset
- `customer_segmentation_results.csv` - Final clustering results
- `requirements.txt` - Required Python libraries

Conclusion
Customer segmentation was performed successfully using K-Means clustering.
The analysis identified groups of customers with similar characteristics.
This project demonstrates the practical use of unsupervised machine
learning for customer analysis and data-driven marketing decisions.
